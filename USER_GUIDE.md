# HomeLibrary — руководство пользователя

HomeLibrary — офлайн-каталог личной библиотеки. Программа читает индекс
**INPX** (стандартный индекс библиотек Librus/Flibusta) и папку с файлами
книг (`.zip`-архивы с `.fb2` внутри или отдельные `.fb2`), показывает
единый список, позволяет искать по автору, названию, серии, жанру,
аннотации и ключевым словам — и экспортировать выбранные книги в `.fb2`.

Программа не выходит в интернет и не изменяет файлы книг: единственное,
что она делает с диском, — читает индекс/архивы и копирует книги при
экспорте.

---

## 1. Системные требования

| Вариант | Что нужно |
|---|---|
| Готовый `HomeLibrary.exe` | Windows 10/11, ничего доустанавливать не нужно |
| Запуск из исходника | Python 3.12+ (подойдёт 3.13/3.14), стандартный `tkinter` |
| Перетаскивание файлов мышью | необязательный пакет `tkdnd`; без него всё работает, кроме drag&drop |

---

## 2. Запуск

**Из exe:** двойной клик по `HomeLibrary.exe`.

**Из исходника:**

```powershell
py -3.12 homelib.py
```

При первом запуске рядом с исходником можно положить картинку `book.png` —
она появится на вкладке «Поиск» (необязательно).

---

## 3. Первый запуск: три шага

1. Нажмите **«Загрузить библиотеку»** на верхней панели.
2. В диалоге **«Шаг 1»** выберите файл индекса **`*.inpx`**.
3. В диалоге **«Шаг 2»** выберите папку, где лежат книги
   (`*.zip` с fb2 внутри и/или `*.fb2`).

Появится окно **«Индексация коллекции»** с прогрессом. Дождитесь сообщения
**«Индексация завершена. Загружено N книг»** — список книг готов.

> Индексация идёт в фоне: окно программы не «замерзает». Прервать можно,
> закрыв окно прогресса крестиком — текущая индексация отменится.

---

## 4. Интерфейс

```
┌──────────────────────────────────────────────────────────────────┐
│ [Загрузить библиотеку] [Экспорт FB2] [⚙]   INPX: … / Папка книг: …│
├───────────────┬──────────────────────────────────────────────────┤
│ Поиск │ Жанры │ Авторы │  #  Автор  Название  Серия  Жанр  Размер │
│               │        │  ☐ Выбрать все                           │
│  поля поиска  │        │  список книг                             │
│  [Найти]      │        │                                          │
│  [Очистить]   │        │                                          │
├───────────────┴──────────────────────────────────────────────────┤
│ Книг: 0                                                          │
└──────────────────────────────────────────────────────────────────┘
```

- **Верхняя панель** — загрузка библиотеки, экспорт, меню настроек,
  текущие пути к индексу и папке книг.
- **Левая панель** — три вкладки: «Поиск», «Жанры», «Авторы».
- **Справа** — таблица книг и галочка «Выбрать все».
- **Нижняя строка** — количество книг в текущем списке.

⚠ Значок меню настроек — кнопка **⚙** (в некоторых шрифтах выглядит как «?»).

---

## 5. Поиск

Вкладка «Поиск» ищет по уже загруженному списку, ничего не перечитывая с
диска. Все поля необязательны — пустое поле не ограничивает выборку.

| Поле | Как ищет |
|---|---|
| Автор | подстрока без учёта регистра |
| Название | подстрока без учёта регистра |
| Серия | подстрока без учёта регистра |
| Жанр | выпадающий список; фильтр по коду жанра |
| Аннотация | подстрока без учёта регистра |
| Ключевые слова | подстрока без учёта регистра |

Условия складываются по «И»: заполнили автора и название — найдутся книги,
где совпадает и то, и другое.

- **«Найти»** — применить фильтр.
- **«Очистить»** — сбросить все поля и показать весь список.

---

## 6. Жанры

Вкладка «Жанры» показывает дерево: крупные категории (Фантастика, Детективы,
Классика и т.д.) и внутри — конкретные жанры.

- **Одиночный клик** запоминает выбранный жанр/категорию.
- **Двойной клик** по конкретному жанру подставляет его в поле «Жанр» на
  вкладке «Поиск» и сразу выполняет поиск.
- Кнопка **«Показать книги жанра»** фильтрует список по выбранному жанру
  или категории (категория — это объединение всех её жанров).

---

## 7. Авторы

- Список авторов строится по загруженному индексу.
- Поле **«Поиск автора»** фильтрует список по мере ввода.
- **Двойной клик** по автору подставляет его в поле «Автор» и ищет книги.
- Кнопка **«Показать книги автора»** фильтрует список по выбранному автору.

---

## 8. Список книг

Колонки: **#**, **Автор**, **Название**, **Серия**, **Жанр**, **Размер**.

- **Клик по заголовку колонки** — сортировка; повторный клик меняет
  направление. Сортировать можно по автору, названию, серии, жанру, размеру.
- **«Выбрать все»** — отметить/снять все книги в текущем списке.
- **Правая кнопка мыши** по книге — контекстное меню «Экспорт FB2»
  (работает, если есть выделение).
- **Двойной клик** по книге — сразу экспорт выделенных книг.

> Сортировка по колонке `#` в этой версии не работает (падает на пустом
> списке индексов). Это особенность текущей сборки; остальные колонки
> сортируются нормально.

---

## 9. Экспорт FB2

1. Выделите одну или несколько книг (Ctrl/Shift — как обычно в Windows).
2. Нажмите **«Экспорт FB2»** (или двойной клик по книге).
3. Выберите папку для сохранения.

Правила:

- Имя файла: `Автор - Название.fb2`, а если у книги есть серия —
  `Автор - [Серия] Название.fb2`.
- Недопустимые для имён символы заменяются на `_`; автор обрезается до
  50 символов, название — до 100.
- Если книга лежит в `.zip`-архиве — из архива извлекаются все `.fb2` и
  переименовываются в выбранное имя.
- Если книга — отдельный `.fb2` — файл копируется.
- В конце показывается отчёт: **«Сохранено: X, Ошибок: Y»**.

Ошибка засчитывается, если: у книги не найден файл (архив не сопоставлен,
файл удалён/перемещён) или архив не является zip / не содержит `.fb2`.

Экспорт всегда спрашивает папку. Настройка «Папка экспорта по умолчанию»
сохраняется в конфиге и в коллекциях, но текущая версия при экспорте
всё равно открывает диалог выбора папки.

---

## 10. Коллекции

Коллекция — это запомненная пара «INPX + папка книг + папка экспорта».

Меню **⚙**:

- **«Сохранить коллекцию»** — введите имя, и текущие пути сохранятся.
- **«✓ Имя коллекции»** — переключиться на коллекцию (галочка — активная).
- **«✕ Удалить коллекцию»** — если коллекция одна, спросит подтверждение;
  если несколько — покажет нумерованный список и попросит ввести номер.

При следующем запуске программа автоматически загружает первую сохранённую
коллекцию (без диалогов) — удобно, если библиотека одна.

---

## 11. Папка экспорта по умолчанию

**⚙ → «Папка экспорта по умолчанию»** — выберите папку, она запомнится в
конфиге. (См. примечание об экспорте в разделе 9.)

---

## 12. Перетаскивание файлов (drag&drop)

Работает, если установлен `tkdnd`.

- Перетащите **папку с книгами** в окно — программа просканирует её,
  добавит новые `.zip`/`.fb2`, пересопоставит книги с файлами и покажет:
  «Добавлено: X архивов, Y fb2».
- Перетащите **INPX-файл** — программа напомнит, что для индексации нужен
  ещё и путь к папке книг (перетащите папку).

---

## 13. Где хранятся настройки

```
%USERPROFILE%\HomeLibrary_data\config.json
```

Содержимое:

```json
{
  "default_export_folder": "D:\\Books\\Export",
  "saved_collections": {
    "Моя библиотека": {
      "inpx_path": "D:\\Books\\index.inpx",
      "books_path": "D:\\Books\\Files",
      "default_export": "D:\\Books\\Export"
    }
  }
}
```

Удаление файла = сброс настроек и коллекций.

## 14. Что ожидается на диске

**INPX** — zip-архив с индексными файлами `.inp`. Каждая строка книги
состоит из полей, разделённых символом `\x04` (как в стандарте INPX):

```
Автор \x04 Жанр \x04 Название \x04 Серия \x04 НомерВСерии \x04 ИмяФайла \
\x04 Размер \x04 ВнутреннийНомер \x04 Удалена \x04 Расширение \x04 Дата \
\x04 Язык \x04 Рейтинг \x04 КлючевыеСлова
```

- Автор в формате `Фамилия,Имя,Отчество` превращается в
  `Фамилия Имя Отчество`.
- Пустое название → «Без названия», пустой автор → «Неизвестный».
- Серия с номером отображается как `Серия #номер`.
- Строки короче 14 полей пропускаются.

**Папка книг** — плоский список файлов:

- `*.zip` — архивы с `.fb2` внутри;
- `*.fb2` — отдельные книги.

**Сопоставление книги с файлом** идёт по имени файла из индекса:

- для zip — по первым **15** символам имени архива (без учёта регистра);
- для fb2 — по первым **20** символам имени файла без расширения.

Поэтому имена архивов/файлов на диске должны начинаться так же, как
`ИмяФайла` в индексе. Если книга не сопоставилась, она видна в списке, но
экспорт по ней даст ошибку.

## 16. Решение проблем

**После индексации список пуст.**
Проверьте, что INPX содержит `.inp`-файлы и что строки разделены `\x04`.
Пустая папка книг не мешает списку — книги будут без файлов, но видимы.

**Книги есть, но экспорт даёт «Ошибок: N».**
Значит, файлы не сопоставились: проверьте имена архивов/`fb2` (первые 15/20
символов) и что INPX непустой.
Убедитесь, что у книг есть файл: в таблице нет колонки «файл», но при
наведении на книгу в статусе экспорта будет ошибка именно по таким записям.

**«Файлы коллекции не найдены. Удалите коллекцию или выберите новую».**
Пути, сохранённые в коллекции, больше не существуют (диск отключён, папка
переименована). Перезагрузите библиотеку вручную и сохраните коллекцию
заново.

**Нет перетаскивания файлов.**
Не установлен `tkdnd` — это не ошибка; пользуйтесь кнопкой «Загрузить
библиотеку».

**Индексация идёт долго.**
Большой INPX разбирается построчно в фоне; прогресс показывает «Найдено N
файлов…» и «Книг: N». Можно отменить, закрыв окно прогресса.

**Кракозябры или пустые названия/авторы.**
Индекс читается как UTF-8 с игнорированием ошибок. Если ваш `.inp` в другой
кодировке, часть полей может потеряться — перекодируйте индекс в UTF-8.

**Сортировка по `#` роняет программу.**
Известная особенность этой версии — сортируйте по другим колонкам.

## 17. Ограничения текущей версии

- Все книги держатся в памяти — библиотеки на сотни тысяч записей требуют
  много RAM и грузятся заметное время.
- Флаг «удалена» из INPX сохраняется в данных, но список не фильтрует.
- Нет редактирования метаданных и чтения книг — только каталог и экспорт.
- Экспорт всегда спрашивает папку (см. раздел 9).
- Сортировка по колонке `#` не работает.
- Размер книги показывается в Б/КБ/МБ/ГБ; для очень больших значений
  остаётся в ГБ.
