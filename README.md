# HomeLibrary

Офлайн-каталог личной библиотеки: читает индекс **INPX** и папку с
книгами (`.zip` с `.fb2` внутри или отдельные `.fb2`), даёт поиск по
автору/названию/серии/жанру/аннотации/ключевым словам и экспортирует
выбранные книги в `.fb2`.

Репозиторий содержит **восстановленный исходный код** программы
`HomeLibrary.exe` (PyInstaller-сборка, Python 3.12). Исходники получены
декомпиляцией `homelib.pyc` декомпилятором
[pycdc](https://github.com/zrax/pycdc) с патчами под байткод Python 3.12;
битые места восстановлены вручную по дизассемблеру `pycdas` и сверены
функция за функцией.

## Содержимое

| Файл | Что это |
|---|---|
| `homelib.py` | Исходник приложения (≈1200 строк, UTF-8), отформатирован black |
| `USER_GUIDE.md` | Подробное руководство пользователя |
| `homelib_disasm.txt` | Дизассемблер оригинального `homelib.pyc` — эталон для сверки |
| `README.md` | Этот файл |

## Быстрый старт

```powershell
py -3.12 homelib.py
```

Подойдёт Python 3.12+ с `tkinter` (входит в установку Python для Windows).
Для drag&drop нужен необязательный пакет `tkdnd`; без него приложение
работает, просто файлы нельзя перетаскивать мышью.

Дальше: **«Загрузить библиотеку»** → выбрать `.inpx` → выбрать папку с
книгами. Подробности — в [USER_GUIDE.md](USER_GUIDE.md).

## Как это проверялось

- Сверка с байткодом: все code-объекты из `.pyc` присутствуют в исходнике,
  ни в одной функции не потеряно ни одного имени/вызова.
- Синтаксис: `py_compile` — OK.
- Smoke-тесты на реальном Tk (окно скрыто): построение всего интерфейса,
  разбор INPX-строки, сортировки, поиск, жанры, авторы, «Выбрать все»,
  сохранение/загрузка конфига, сопоставление книг с файлами, форматирование
  размера — проходят.
- Код отформатирован `black` (line-length 100).

## Сборка exe

```powershell
py -3.12 -m pip install pyinstaller
py -3.12 -m PyInstaller --onefile --noconsole --name HomeLibrary homelib.py
```

Если нужен drag&drop — установите `tkdnd` до сборки и добавьте его
Tcl-библиотеку через `--add-data`.

## Особенности оригинала (сохранены намеренно)

- Отладочные `print` (`[PARSE]`, `[DnD]`, `[EXPORT]`, «Связано с файлами»)
  есть в байткоде и оставлены как есть.
- Сортировка по колонке `#` падает с `ValueError` (`list.index` во время
  `list.sort`) — это поведение оригинальной сборки, а не ошибка
  декомпиляции.
- Флаг «удалена» из INPX сохраняется, но список не фильтрует.
- `format_size` за пределами ГБ продолжает показывать ГБ.
